# 小さな幸せボックス（第1版）

## できること
- 日本語の音声入力（対応ブラウザのみ）
- 入力内容と本人が決めたポイントの保存
- 累計ポイント・今日のポイント・記録一覧
- JSON形式のバックアップと読み込み
- PWAとしてホーム画面に追加（HTTPSで公開した場合）

## 保存について
記録は利用中のブラウザの localStorage に保存されます。同じ端末・同じブラウザで使う限り保持されますが、ブラウザのデータ消去や端末故障で失われる可能性があります。定期的に「記録をバックアップ」を押してJSONファイルを安全な場所へ保存してください。現時点ではクラウド同期ではありません。

## 音声入力について
AndroidのChromeなど、Web Speech APIに対応したブラウザが必要です。音声認識はブラウザ側の機能に依存し、端末・ブラウザ・ネット接続・権限によって動作が異なります。初回はマイク使用を許可してください。

## 公開とホーム画面への追加
PWAとしてインストールするにはHTTPSで公開する必要があります。GitHub Pages等にこのフォルダのファイルを配置して公開し、XperiaのChromeで公開URLを開き、メニューから「ホーム画面に追加」または「アプリをインストール」を選びます。

## 注意
この版は端末内保存です。別端末との自動同期、ログイン、クラウドバックアップはまだありません。
